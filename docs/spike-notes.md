## Decisions
- Executor is Direct_Adapter for the MVP. Fluxnova is deferred (`backlog.md`).
- Decider and Bedrock are remote; Fluxnova, py-pglite, CALM and Spectral run locally. Repointing (for example to EC2) is a `.env` change only.
- Decider unavailable gives `unavailable` answers with no risk-reducing default (`DECIDER_PROVIDER=fixture` for tests and demos).
- Bedrock unavailable: `MODEL_PROVIDER=none` or `replay` with recorded outputs.
- pglite failure: YAML seed + file export, then SQLite.
- Spectral or CALM failure: adapter returns ERROR, never VALID. Spectral results are parsed from JSON, not from the exit code.
- Adapters must re-check real tool output shapes in their integration smoke tests (tasks 2.9 and 3.14).

## Findings during implementation (tasks 5-14)
- `calm generate` 1.60.1 omits `enum` metadata properties entirely (no placeholder). Placeholder_Fill adds them from the attributes; a required property still missing is reported as a leftover.
- `options` work through `prefixItems` positions with `oneOf`/`anyOf` alternatives; `items` catalogues are not generated by 1.60.1. Optional positions must come last, and `oneOf` choices must name the same number of items, or the generated model no longer lines up with `prefixItems` on validation (the Composer enforces both).
- An `anyOf` option with an empty selection makes `calm validate` crash (`Cannot read properties of undefined (reading 'description')`). RA03-LITE therefore has an explicit "No audit service" choice.
- Pattern lint rejects zero values (`pattern-has-no-empty-properties`) and empty `relationships`; single-component patterns carry a connection-point node and one relationship.
- `calm generate` can wait on stdin; the adapters pass `stdin=DEVNULL` and resolve `.cmd` shims with `shutil.which`.
- Spectral 6.17.1 re-checked on CALM App_Models: results parsed from the first JSON array on stdout (a trailing text line can follow).
- Recorded CLI outputs for V1-V4 live in `governance-execution-framework/fixtures/recordings/cli/`; tests use them unless `AGIP_REAL_TOOLS=1`.
